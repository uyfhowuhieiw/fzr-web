# 肥美先生烦着瑞 · 粉丝主页

一个纯静态的单页网站：打开就是配乐主页，人物照片渐入 + 标题渐入，底部三个按钮分别打开
「个人简介」「介绍视频」「小游戏」三个弹窗，每个弹窗右上角都有叉可以关掉。

## 怎么打开

推荐用自带的本地服务器（音乐自动播放和读取轮廓数据在 `file://` 下会被浏览器限制）：

```powershell
# 在 fzr 文件夹里执行
& "C:\Users\62957\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\node\bin\node.exe" serve.js
```

然后浏览器打开 <http://127.0.0.1:8123/>

也可以直接双击 `index.html`。页面本身能正常显示和使用，只是个别浏览器会拦下背景音乐的自动播放
（点一下页面任意位置或「播放BGM」按钮即可开始）。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构：主页 + 三个弹窗 |
| `style.css` | 女神异闻录5风格样式（黑 / 红 / 白 · 斜切 · 半调网点） |
| `app.js` | 入场动画、逐字标题、轮廓线描、背景音乐、弹窗开关 |
| `video.js` | 「介绍视频」：全部由代码实时绘制的手书动画（Canvas 2D + WebAudio 合成音效） |
| `pacman.js` | 「小游戏」：吃豆人，主角换成军帽将军头像 |
| `serve.js` | 本地预览用的小服务器（可选） |
| `assets/portrait.jpg` | 人物照片（由原图 `1426[1].jpg` 复制而来） |
| `assets/bgm.ogg` | 背景音乐（由原文件 `CYPN - 3strikes(苹果进行曲)_L.ogg` 复制而来） |
| `assets/silhouette.json` | 从照片里提取的侧脸轮廓 + 细节笔触，供线描动画使用 |

原始的 `1426[1].jpg` 和 `CYPN - 3strikes(苹果进行曲)_L.ogg` 保持原样未改动。

## 三个按钮

1. **个人简介** —— 弹窗显示 `{范哲睿太肥美哈哈哈}`，下面附一张资料卡。
2. **介绍视频** —— 约 31 秒的女神异闻录5风格手书：黑场标题 → 惊闪 → 轮廓显形（照片淡出、
   红色剪影 + 线描逐段画出）→「肥美范哲睿」逐字冲击 → 五人定格 → 片尾。右下角有
   「重播 / 跳到结尾 / 音效开关」，音效是实时合成的，没有使用任何视频文件。
3. **小游戏** —— 吃豆人：红色迷宫 + 四色幽灵，吃豆人形象换成了军帽 + 绿色军装 + 黑框眼镜的
   将军头像（会张嘴啃豆）。方向键 / WASD 移动，`P` 暂停，`R` 重开，手机可以滑动屏幕。
